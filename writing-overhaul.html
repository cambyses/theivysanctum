Priority Release

The Sanctum clock.

Priority Release reserves a defined response window for time under the control of The Ivy Sanctum.

How the clock works

The clock begins when every material required for the relevant stage has been received. It ends when The Ivy Sanctum releases that stage of work back to the applicant.

Complete Material → Sanctum Clock Begins → Sanctum Release → Clock Ends

Two-Pass example

A 48-hour Priority Release begins when the complete first draft is received. The first Sanctum return is released within 48 hours. The applicant then controls the revision period. When the rewritten draft is uploaded, a new 48-hour Sanctum clock begins for the final pass.

Draft Received → 48 Hours → First Return → Applicant Revision → Revised Draft Uploaded → New 48-Hour Clock → Final Return
