Priority Release

The Sanctum clock.

Priority Release reserves a defined response window for time under the control of The Ivy Sanctum.

How the clock works

The clock begins when every material required for the relevant stage has been received. It ends when The Ivy Sanctum releases that stage of work back to the applicant.

Complete Material → Sanctum Clock Begins → Sanctum Release → Clock Ends

Multi-stage engagements

Application Strategy and Application Architecture contain more than one Sanctum-controlled stage. Applicant review, rebuilding, and revision periods sit between those stages. Each new Sanctum response window begins when the materials required for that stage are received.

Sanctum Return → Applicant Work → Revised Material Received → New Sanctum Clock
