Advisory

Strategy built around the file.

Reader-grade diagnostics, essay architecture, recommender strategy, application positioning, and full-file advisory for selective admissions.

Each engagement begins with the application problem in front of us and applies the level of analysis, architecture, and written strategy required to move the file forward.

Ways to Work

Choose the pressure point.

Some files need diagnosis. Some need focused work on essays, activities, recommendations, or school-specific writing. Others benefit from full application architecture across the entire file.

Diagnose

Establish how the file reads, where its strongest proof sits, and which strategic moves carry the greatest value.

Develop

Work directly on the component carrying the most pressure: statement, supplements, activities, recommendations, or positioning.

Architect

Private Written Work

File Read

$233

A reader-grade assessment of the current application file.

The File Read establishes the file’s first impression: academic rigor, GPA and testing context, activity signal, school-list alignment, essay material or early angles, and the opening layer of recommender posture. It identifies the strongest admissions signal, the primary pressure point, and the most intelligent next move.

The output is an annotated file read with a written reader memo. The purpose is clarity before deeper architecture: what the file is already carrying, where its authority concentrates, and which move should come first.

Strategy Diagnostic

$466

A full diagnostic of the application as a single admissions argument.

The Strategy Diagnostic reads academic context, narrative spine, positioning, activities architecture, school-list logic, recommender strategy, essay direction, and fit pressure as one system moving through a reader’s mind. It clarifies what the application is proving, which evidence carries the most authority, and how each component should be sequenced for maximum force.

The output is a written strategy memo with margin notes and a build sequence. The memo defines the file’s governing argument, proof hierarchy, priority upgrades, and 4–12 week strategic path.

Statement Architecture

$727

A strategic architecture pass on the personal statement or central admissions essay.

The statement is treated as the file’s central movement: a controlled piece of evidence with consequence, rhythm, and proof. The work clarifies the essay’s governing claim, opening position, evidence sequence, paragraph pressure, reader consequence, and final movement.

The output is an annotated draft, architecture memo, and revision directives calibrated to the essay’s admissions function. The candidate’s voice remains intact; the structure becomes sharper, more deliberate, and more compelling.

Statement Build

$987

A complete personal-statement build from raw material through final admissions architecture.

The work begins with ideation, evidence excavation, intellectual and personal positioning, angle selection, and fit within the larger application. From there, the statement develops through governing claim, opening position, structural spine, evidence sequence, paragraph movement, reader consequence, revision, and final calibration.

The output is an ideation map, evidence inventory, angle strategy, structural architecture, annotated development, revision direction, and final reader calibration. The result is a statement built around a clear admissions function, strong evidence, and controlled movement.

Supplements Map

$787

School-specific strategy for up to seven supplements.

The Supplements Map assigns each response a distinct function inside the larger file: intellectual fit, institutional reason, contribution logic, academic direction, community signal, or proof expansion. The work clarifies prompt strategy, school-specific fit, claim distribution, essay-to-activity alignment, and evidence placement across the supplement set.

The output is a complete supplement map with annotated drafts, margin notes, and readiness guidance. Each school receives a precise reason to believe the candidate belongs in its room.

Microcopy

$377

A precision review of Activities, Honors, and Additional Information.

Microcopy shapes reader inference in the smallest fields of the application. This work strengthens role clarity, artifact, metric, hierarchy, compression, honors framing, contextual explanation, and proof density across the application’s compressed sections.

The output is revised microcopy with strategic framing notes. The result is cleaner signal, stronger hierarchy, sharper evidence, and tighter alignment between the compressed sections and the larger file.

Recommender Memo

$377

A strategic memo for recommendation-letter architecture.

Recommendation letters function as third-party evidence. The Recommender Memo identifies the strongest recommender pairing, the role each letter should play, and the evidence each writer can carry with proximity and authority.

The output is a Macro × Micro recommender map, evidence distribution, letter calibration, and Evidence Brief guidance. The goal is a recommendation structure that verifies the file’s strongest claims with specificity, credibility, and force.

Oxford / UK Statement

$466

A strategic review of the UCAS, Oxford, Cambridge, or UK academic statement.

UK admissions writing is evaluated through academic seriousness: subject command, intellectual trajectory, preparation, course fit, reading, research, and disciplined engagement. This review sharpens the statement’s governing argument, strengthens academic proof, calibrates course fit, and gives the statement a cleaner intellectual line.

The output is an annotated draft, structure memo, targeted revision directives, and course-fit calibration. The result is a statement that reads with authority, focus, and intellectual credibility.

Application Sprint

$1,597

A seven-day application lock-in for candidates approaching deadline.

The Sprint brings existing application materials into one coherent admissions system. It covers personal statement architecture, up to five supplements, microcopy, activities alignment, claim distribution, school-specific fit, and final submission readiness.

The output is a set of written strategy memos, annotated documents, margin notes, refined application components, and a final readiness audit. The result is a file with clearer hierarchy, stronger proof, and disciplined coherence under deadline pressure.

Full File Architecture

$2,397

A full strategic build of the application file as a reader will encounter it.

Full File Architecture aligns the candidate’s academic record, activities, essays, recommendations, school list, and fit logic into one admissions argument. The work establishes identity pillars, personal statement spine, activities architecture, recommender matrix, Evidence Briefs, supplement strategy, school-specific fit map, and final readiness architecture.

The output is a sequence of written strategy letters, margin notes, and structured file decisions across the build. The result is a file that reads with coherence, proof, restraint, and force.
